## 목적

토큰 발급과 검증, admin 로그인, 권한 판단, 인증 실패 로그를 구현한다.

## 근거

- 명세 §5 권한과 토큰, §5-1 admin 로그인, §5-2 프로젝트 토큰 만료, §8 보안 원칙, §8-1 인증 실패 로그

## 선행

- 0002 (0003과 병행 가능)

## 할 일

- [ ] 프로젝트 토큰 발급: 무작위 값 생성, 값은 한 번만 반환, 해시만 저장, `read`/`write`, 만료일(생성 시 지정, 무기한 가능, 이후 변경 불가)
- [ ] 토큰 폐기(admin)
- [ ] admin 로그인: `HCS_ADMIN_PASSWORD` 상수 시간 비교, 8자 미만·미설정이면 admin 로그인 비활성(경고), 실패 시 일정 지연
- [ ] admin 토큰: 서버 자동 생성, 12시간 만료, 로테이션 없음, 서버 재시작 시 모두 폐기
- [ ] 권한 판단: 토큰 없음 / `read` / `write` / admin 매트릭스, `public` 저장소 읽기 허용
- [ ] admin 토큰은 `/ui/api/*`에서만 허용, REST·MCP에서는 거부
- [ ] 권한 없음과 없음을 같은 `404`로 응답
- [ ] 인증 실패 로그: `<ISO8601 UTC> hcs auth_failed ip=<IP> kind=<admin_login|bearer> path=<경로>` 한 줄, 비밀번호·토큰·본문 제외
- [ ] `HCS_TRUSTED_PROXIES`에 있는 프록시에서만 `X-Forwarded-For` 신뢰
- [ ] 감사 기록(Audit): 쓰기·관리 동작 기록, 값·본문 제외
- [ ] 테스트: 권한 매트릭스, 404 동일성, 만료·폐기, 로그 형식(정규식으로 검증)

## 완료 조건

- 권한 매트릭스와 404 동일성, 인증 실패 로그 형식이 테스트로 고정되어 있다.
- 로그 어디에도 토큰·비밀번호·본문이 나오지 않는다는 테스트가 있다.
